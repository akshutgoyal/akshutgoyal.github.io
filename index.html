01

From interface to infrastructure

I’m a full-stack developer and B.Tech student at Delhi Technological University. I like working across an application: building the interface, writing APIs, connecting the database and getting it deployed.

RoadSense brings together a Flutter app, a React dashboard, AWS and on-device pothole detection. ApnaRecord explores patient-owned records, connecting a web interface to Solidity contracts and wallet-based access.

Beyond web development, I build Linux desktop tools and browser automation in the Aethel suite. I’m looking for an internship where I can contribute to a team, and I’m also available for freelance web projects.

  • Web applications

    React, Vue, Laravel and CodeIgniter; APIs with Node.js, Express and FastAPI.

  • Cloud & data

    MySQL, MongoDB, Redis and DynamoDB; AWS infrastructure defined with CDK.

  • ML in RoadSense

    YOLOv8, PyTorch and ONNX, with TensorFlow Lite inference on the phone.

  • Blockchain in ApnaRecord

    Solidity, OpenZeppelin and ethers.js on Base Sepolia, with MetaMask wallet access.
